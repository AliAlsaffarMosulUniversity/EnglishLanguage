# English for Iraq – الصف الخامس الابتدائي

تطبيق لتعلّم الإنكليزية للصف الخامس الابتدائي (العراق): منهج الوحدات الثماني، بطاقات الكلمات، الكلمات الصعبة، الاستماع والنطق الإنكليزي، اختبارات بعدد أسئلة يحدده الطالب، وألعاب تعليمية.

- يعمل على الهاتف والآيباد والحاسوب، ويُثبَّت كتطبيق ويعمل دون إنترنت.
- الترجمة العربية تظهر عند ضغط زر «ترجمة».
- وضع ليلي ونهاري.

تصميم وتطوير: علي الصفار .. دعم لبراعم العراق
